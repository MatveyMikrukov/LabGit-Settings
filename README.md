# LabGit-Settings

Лабораторная работа по настройке репозитория.

## Назначение проекта

Учебный проект для изучения возможностей GitHub: создание репозитория, загрузка файлов через веб-интерфейс, организация структуры каталогов, настройка фильтров `.gitignore` и правил обработки файлов `.gitattributes`, фиксация изменений коммитами.

## Структура каталогов

```text
LabGit-Settings/
├── src/            исходный код (Program.cs)
├── docs/           документация (description.txt)
├── tests/          тестовые материалы
├── assets/         вспомогательные материалы
├── .gitignore      правила исключения файлов
├── .gitattributes  правила обработки типов файлов
└── README.md       описание проекта
```

## Типы файлов, исключаемые из отслеживания (.gitignore)

- каталоги сборки: `build/`, `bin/`, `obj/`;
- временные файлы: `temp/`, `*.tmp`, `*.temp`;
- журналы: `logs/`, `*.log`;
- локальные настройки и секреты: `.env`, `appsettings.Local.json`;
- файлы ОС: `Thumbs.db`, `.DS_Store`;
- файлы среды разработки: `.vs/`, `.vscode/`, `*.user`, `*.suo`;
- результаты тестирования: `TestResults/`.

## Использованные настройки репозитория

- `.gitignore` — исключение служебных, временных и секретных файлов;
- `.gitattributes` — `* text=auto`; `*.cs` — CRLF; `*.md`, `*.txt` — LF; `*.png`, `*.jpg`, `*.pdf`, `*.zip` — бинарные файлы;
- учебные файлы `build/result.txt`, `logs/app.log`, `temp/cache.tmp` и `.env` удалены из текущей версии репозитория.
